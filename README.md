# Victor Mallick (`@Wizardezgg`) — Portfolio

Minimal gaming-HUD portfolio built with **Next.js 15**, **React 19**, **TypeScript**, and **Tailwind CSS**.

## Overview

- **01 // HOME** — Interactive 360° radial navigation wheel & operator bio
- **02 // BOSSES** — Featured full-stack & AI systems (**MatchPoint AI**, **Aperture**) with architecture pipelines and live interactive demos
- **03 // GIGS** — Shipped web applications (**Bazar Dor**, **FitLog**, **Dev Stack Builder**)
- **04 // SKILLS** — Full-screen tech stack matrix & 1-click PDF resume generator
- **05 // UPLINK** — Direct contact form & social links
- **3D Background** — Interactive 3D warp starfield with cursor hex-grid spotlight
- **Command Palette** — `Ctrl + K` quick navigation and actions

## Tech Stack

- **Framework:** Next.js 15 (App Router) + React 19
- **Styling:** Tailwind CSS
- **Utilities:** `jspdf` (client-side PDF resume), `sonner` (notifications), HTML5 Canvas & Web Audio API

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
